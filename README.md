# 3Week Calendar

월 단위가 아닌 앞으로의 21일을 보여주는 미래 중심 캘린더

## Features

- 연속형 3주(21일) 캘린더
- 월 경계 없는 일정 확인
- 일정 추가 및 관리
- 한국어 / 영어 지원
- 웹 및 모바일 환경 지원

## Problem

기존 캘린더는 월이 바뀔 때마다 화면을 이동해야 한다.

3Week Calendar는 앞으로의 21일을 연속적으로 보여주어
더 효율적인 단기 계획 수립을 돕는다.

## Tech Stack

- React / Next.js
- Vercel
- Supabase
